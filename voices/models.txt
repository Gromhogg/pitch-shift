# The Realistic mode's AI model files (Apple silicon, Core ML, 8-bit weights; ~133 MB zipped, ~146 MB unpacked).
# Too big for git, so build.sh takes them from a local copy (build/voices/, or research/voicechanger/models/ in this
# checkout or the main one) or downloads them from the address below, checks the SHA-256 sum and unpacks them into
# Contents/Resources/Voices/. To publish: upload the zips whose address says PLACEHOLDER as assets of a GitHub release
# and put its tag in place of PLACEHOLDER.
# 3.0.0 shipped the first-shape files (contentvec, woman, man) from the v3.0.0 release; 3.1.0 to 3.2.0 shipped the
# blends woman_us_ahead and man_ahead (v3.1.0 release).
# The look-ahead shape (Pitch Shift 3.1, "_ahead"): one file per voice serves every "Faster ↔ More real" position
# (convert_generator.py --context-ms 1000 --ahead-ms 700 --right-ms 40; the encoder: convert_contentvec.py
# --context-ms 1710, 1.92 s window). Older voice files (the first shape) still load with this encoder and use no
# look-ahead.
# 3.3.0: Woman and Man are trained voices (Kaggle, 200 epochs on 8 VCTK speakers each, started from the blends;
# research/voicechanger/results/trained.md), converted the same way: woman_us_t200_ahead, man_t200_ahead. New names,
# so the app's "first time" note and Core ML's cache can't mix them up with the blends. The encoder is unchanged.
